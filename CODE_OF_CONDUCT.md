# Code of conduct

Project discussions should stay technical, direct, and respectful. Contributors must not harass people, publish private information, use discriminatory language, or disrupt issue and review threads.

Maintainers may edit or remove abusive content and restrict participation when needed. Report conduct problems privately through the contact method in [SECURITY.md](SECURITY.md). A conduct report should describe what happened and link to the relevant public material when available.

Disagreement about format interpretation is normal. Use specifications, byte examples, and tests to settle it without attacking the person who proposed a change.
