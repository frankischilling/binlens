# Security policy

## Supported versions

Security fixes are provided for the latest tagged BinLens release and the current `main` branch.

## Report a vulnerability

Use the repository's private security advisory form at `https://github.com/frankischilling/binlens/security/advisories/new`. Do not open a public issue for an input that crashes the parser, consumes unbounded resources, escapes terminal sanitization, or reads outside the file.

Include the affected command or library call, BinLens version, operating system, parser limits, and the smallest input you can share. If the file may contain copyrighted or sensitive data, describe how to reproduce it with generated bytes instead of attaching the original.

The maintainer will acknowledge a report within seven days. Fix timing depends on severity and reproducibility. A coordinated advisory will credit reporters who want attribution.

## Scope

Relevant reports include unchecked offset arithmetic, parser nontermination, excessive allocation from declared sizes, terminal escape injection, unsafe release workflows, and parser exceptions that cross the public boundary. Incorrect field labels without a security effect belong in the parser bug template.
